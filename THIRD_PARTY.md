Its upstream repository does not currently provide an explicit redistribution license, so public
releases should require developers to obtain it separately or configure a legally obtained key.

public source repository or redistributed without permission. Developers must obtain it from an
environment they legally own and comply with its license.

Game assets, AES keys, UE4SS, and proprietary game files are not part of this project's source.
